# feature-development

새 기능 추가 절차:
1. 요구사항을 한 문장으로 정의하고, **성공 기준(무엇이 되면 "완료"인지)을 먼저 정한다**
   (예: "LED 제어 추가" → "대시보드 버튼을 누르면 Mock LED 상태가 바뀌고 화면에도
   반영된다")
2. 역할 지정 문구("너는 이 프로젝트의 [역할]-agent다")로 시작하는 프롬프트를 작성한다.
   karpathy-principles.md의 "외과적 변경" 원칙에 따라 관련 없는 파일은 건드리지 않는다
3. 코드 생성 결과를 받으면 학생이 직접 실행해서 확인한다
4. 1단계에서 정한 성공 기준을 실제로 충족하는지 눈으로 검증한다 — 요약만 읽고
   다음 단계로 넘어가지 않는다
5. 통과하면 커밋한다 (git-rules.md의 GUI 업로드 방식)
