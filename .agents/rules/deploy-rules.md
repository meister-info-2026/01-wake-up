# 배포 규칙

- 환경변수(Supabase URL/키, 디바이스 API 키 등)는 코드가 아니라 Render/Vercel 대시보드에서
  직접 설정한다
- 로컬에서 정상 동작을 확인한 뒤에만 배포한다 (로컬 실행 → 통과 → 배포 순서를 지킨다)
- 배포 브랜치는 `main`으로 고정, 배포 전 반드시 최신 `main`을 pull 받은 상태에서 확인한다
- 배포 후에는 반드시 실제 배포 URL로 접속해서 헬스체크(`/health`, `/docs` 등)까지
  확인한다 — "Deployed로 표시된다"와 "실제로 동작한다"는 다르다
