# 영상인식 규칙

## 개인정보 보호 (필수 — 반드시 지킨다)
- 영상은 Windows PC 로컬에서만 처리한다 — 원본 영상을 클라우드에 업로드하지 않는다
- 얼굴을 식별(누구인지 특정)하거나 얼굴 이미지를 저장하지 않는다
- 백엔드로는 "감지 여부/개수/신뢰도" 같은 최소 정보만 이벤트로 전송한다
  (예: `{"event_type": "person_detected", "detected": true, "count": 1, "confidence": 0.87}`)
- 캠 사용 사실을 촬영 대상(학생/교사)에게 미리 고지한다

## 이벤트 전송
- 감지 상태가 바뀔 때만 이벤트를 보낸다 (매 프레임 전송 금지 — 불필요한 트래픽/DB 기록 방지)
- 디바이스향 인증(API 키)으로 `POST /api/v1/vision/events` 호출

## 트리거 로직
- "감지 → 즉시 제어" 판단 로직은 백엔드(backend-agent)에 둔다. vision 클라이언트는
  감지 사실만 보고하고, 실제 제어 판단은 하지 않는다 (관심사 분리)
