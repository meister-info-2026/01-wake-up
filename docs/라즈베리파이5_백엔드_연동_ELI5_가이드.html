Onboarding Guide

라즈베리파이 5 담당자를 위한 첫걸음
"부품 없이 통신부터 100% 끝내기!"

코딩 경험이 적어도 괜찮습니다! 전선 배선이나 납땜은 잠시 잊으세요.
식당의 '주방'과 '서빙 로봇'처럼, 라즈베리파이가 백엔드 컴퓨터와 쪽지(JSON)를 주고받는 원리부터 정복합니다.

1. 하드웨어 배선 제로
전선 쇼트나 핀 파손 걱정 NO! 오직 화면에 찍히는 글자(print)로 성공을 확인합니다.
2. 우체통 비유 (GET/POST)
5세 아이도 아는 '우체통 쪽지함' 비유로 REST API 통신 계약을 직관적으로 이해합니다.
3. 1분 즉석 실행
준비된 test_connection.py 한 줄만 실행하면 오늘 목표를 즉시 달성합니다.
ELI5 Big Picture

우리는 무엇을 만드나요? (식당과 서빙 로봇의 대화)

백엔드와 라즈베리파이는 마치 "식당 주방 게시판"과 "서빙 로봇"의 관계와 똑같습니다.

백엔드 (중앙 우체국 & 주방)
• 알람 시간 계산, 미션 성공 판단, 2차 수면 확인 팝업을 총괄하는 두뇌입니다.
• 주문판(DB)에 "지금 알람 울려라!" 또는 "알람 꺼라!"라고 쪽지를 적어둡니다.
ELI5 역할: "엄마가 식탁 위에 써놓은 오늘의 심부름 메모장"
라즈베리파이 5 (발 빠른 심부름꾼)
• 1초마다 우체국(백엔드)으로 달려가서 새 쪽지가 있는지 확인합니다.
• "알람 울려!"라는 쪽지를 발견하면 방 안에서 소리(부저)를 내고 결과를 보고합니다.
ELI5 역할: "1초마다 식탁을 확인하고 심부름을 해내는 착한 아이"
Core Contract

둘만의 비밀 통신 규칙 3가지 (부록 A 계약)

백엔드 친구와 라즈베리파이 담당 학생은 딱 이 3가지만 맞추면 완벽하게 연결됩니다.

규칙 항목 우리 시스템의 실제 값 ELI5 5세 아이 설명
1. 친구네 집 주소
(BACKEND_URL)		 http://192.168.0.xxx:8000
*같은 와이파이 내 백엔드 PC IP		 "친구네 집 문패 번호예요. localhost라고 적으면 나 자신을 가리키므로 꼭 친구 컴퓨터 IP를 적어야 해요!"
2. 비밀 암호 도장
(DEVICE_API_KEY)		 wake_up_2026_09_05_v1_0_0 "외부 낯선 사람이 장난치지 못하도록, 쪽지 봉투에 찍는 우리 팀만의 특수 암호 스탬프예요."
3. 쪽지함 이름표
(device_id)		 • 부저: buzzer_1
• 터치패드: touch_pad_1		 "우체통 안에 있는 칸막이 이름이에요. 철자 하나라도 틀리면 우체부 아저씨가 편지를 못 찾아요!"
Step 1: Polling

우체통 열어보기 (GET desired-state)

라즈베리파이는 1초마다 백엔드에게 "저 지금 뭐 해야 하나요?"라고 물어봅니다.

물어보는 방식 (요청) GET
# 1초마다 이 주소로 물어봅니다 GET /api/v1/devices/buzzer_1/desired-state # 봉투에 붙이는 비밀 도장 Headers: X-Device-Api-Key: wake_up_2026_09_05_v1_0_0
ELI5: "우체국장님! buzzer_1 칸에 새 편지 들어온 것 있나요?"
돌아오는 답장 (JSON 응답) 200 OK
{ "success": true, "data": { "device_id": "buzzer_1", "desired_state": "ringing", # 알람 켜라! "value": {"sound": "beep_beep"} } }
ELI5: "응! 여기 desired_state가 ringing이라고 적혀있지? 지금 당장 시끄럽게 울려!"
Step 2: Reporting

심부름 끝났다고 보고하기 (POST state)

소리를 켰으면, 백엔드에게 "지시하신 대로 소리 울리기 시작했습니다!"라고 알려줍니다.

보고서 보내기 (POST 요청) POST
POST /api/v1/devices/buzzer_1/state # 보낼 내용 (JSON) { "state": "ringing", "reported_at": "2026-09-06T08:00:00Z" }
ELI5: "국장님! 방금 부저 알람 실제로 켰습니다! 임무 완료 보고합니다!"
웹 대시보드 화면에 즉시 반영!
• 백엔드가 이 보고를 받는 순간, 학생들의 프론트엔드 웹 화면에 "부저 작동 중 (RINGING)" 초록불이 반짝 켜집니다!
• 이로써 백엔드 ↔ 파이 ↔ 프론트엔드 3자 연동이 완벽하게 이어집니다.
Phase 1 Philosophy

빵판은 잠시 안녕! Print문으로 먼저 성공하기

전선을 꽂기 전에 화면 글자로 먼저 성공을 맛보는 것이 프로 개발자의 방식입니다.

❌ 초보자가 좌절하는 흔한 실수
• 시작하자마자 40개짜리 GPIO 핀에 전선 꽂기
• 5V와 GND를 반대로 꽂아 라즈베리파이 태워먹기
• 통신이 안 되는데 부품이 고장 난 줄 알고 헤매기
주의: 통신이 되는지 모르는 상태에서 회로부터 연결하면 문제 원인을 찾을 수 없습니다!
✅ 이번 2차 첫 단계: 100% Mock Print
• 실제 부저 소리 대신 print("삐-삐- 알람!") 출력
• 터치패드 터치 대신 키보드 y 입력으로 센서 보고
• 통신이 100% 성공하면, 그때 전선 2가닥만 부저에 꽂으면 끝!
목표 달성: 콘솔에 성공 로그가 뜨면 오늘 라즈베리파이 임무는 100점 만점입니다!

Blameless SOS

빨간 에러가 떠도 당황 금지! 3초 처방전

에러 메시지는 내 잘못이 아니라 컴퓨터가 힌트를 주는 친절한 안내문입니다.

Connection Refused
비유: 친구가 아직 문을 안 열어줬어요.
처방:
1. 백엔드 PC에서 서버가 켜져 있나요?
2. 라즈베리파이와 백엔드 PC가 같은 Wi-Fi인가요?
404 Not Found
비유: 우체통에 적힌 이름표가 달라요.
처방:
백엔드 DB에 buzzer_1 디바이스가 들어있는지 백엔드 친구에게 확인 요청하세요!
401 / 403 Forbidden
비유: 비밀 암호 도장이 틀렸어요.
처방:
.env 파일의 DEVICE_API_KEY가 백엔드와 정확히 일치하는지 비교하세요!
✨ 이 3가지만 확인하면 어떤 통신 문제도 5분 안에 해결할 수 있습니다!
