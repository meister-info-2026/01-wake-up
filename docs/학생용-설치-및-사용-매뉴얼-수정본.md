# 학생용 설치 및 사용 매뉴얼 (IoT·영상인식 스마트 제어 시스템)

> 이 킷의 `.agents/`(rules/skills/workflows/hooks/agents) 및 핵심 보일러플레이트 코드는 **교사가 이미 다 만들어 놓았습니다.**
> 여러분은 이 기본 파일들을 다시 만들 필요가 없습니다 — 프롬프트에서 "이 스킬/규칙을 참고해서"라고만
> 하면 AI가 알아서 읽고 작업합니다. 이렇게 하면 Gemini 무료 티어 토큰을 80% 이상 아낄 수 있습니다.
> 아래 예시는 "스마트 출입 관리"를 우리 팀 주제로 골랐다고 가정합니다. 다른 주제를 골랐어도
> 방식은 동일합니다 — 예시에 나온 이름만 우리 팀 것으로 바꿔서 따라 하면 됩니다.
>
> 각 단계의 프롬프트/확인 방법은 이 문서를 따르고, 진행 체크만 빠르게 하고 싶다면
> `docs/학생-수작업-로드맵.md` 체크리스트를 함께 씁니다.

## 0단계. GitHub에서 받기 + 하네스 구축 (팀당 딱 한 번만)

### 0-1. 저장소 받기
팀장 또는 백엔드 담당 1명만 하면 됩니다. PowerShell에서:
```powershell
git clone [교사가 안내한 GitHub 저장소 주소] iot-vision-control-system
cd iot-vision-control-system
```
Git이 익숙하지 않다면, GitHub 저장소 페이지에서 **Code → Download ZIP**으로 받아
압축을 풀고 그 폴더로 이동해도 됩니다.

**확인**: `AGENTS.md`, `.agents/`, `docs/`, `backend/`, `frontend/`, `vision/`, `pi/`가 들어있으면 성공입니다 — 공통 인터페이스(`backend/iot/base.py`, `backend/websocket_manager.py`, `frontend/components/dashboard/ConnectionBadge.tsx`)와 모델 가중치(`vision/yolov8n.pt`)는
교사가 미리 완성해서 저장소에 올려둔 것이라 별도 설치 과정이 필요 없습니다.

### 0-2. Antigravity로 열기
Antigravity IDE에서 방금 받은 폴더를 워크스페이스로 엽니다.

### 0-3. 하네스 구축 프롬프트 — 프로젝트 뼈대 완성
스타터 킷에 기본 구조가 준비되어 있습니다. Next.js 프론트엔드 스캐폴드와 백엔드 가상환경을 준비합니다.
> 💡 **참고**: Windows PowerShell에서 `pip freeze`를 할 때는 인코딩 충돌을 방지하기 위해 항상 UTF-8로 저장합니다:
> `pip freeze | Out-File -Encoding utf8 requirements.txt`

Antigravity 채팅창에 아래 프롬프트를 입력해 스캐폴드를 완성합니다:

```
이 프로젝트에는 이미 AGENTS.md, .agents/ 하네스, 그리고 기본 보일러플레이트(backend/iot/base.py, backend/websocket_manager.py, vision/yolov8n.pt 등)가 준비되어 있어. 
AGENTS.md의 기술 스택과 폴더 구조를 참고해서 아래를 완성해줘.

1. frontend/ — Next.js(TypeScript, Tailwind) 프로젝트 스캐폴드 (.env.example 충돌 없이 생성)
2. backend/ — Python venv를 활성화하고 requirements.txt(fastapi, uvicorn[standard], websockets, pymysql, python-dotenv, httpx 포함)의 패키지를 설치해줘
3. .gitignore — venv/, __pycache__/, *.pyc, .env, .env.local, node_modules/, .next/ 를 포함해줘
4. 각 폴더의 .env.example을 확인하고 누락된 항목이 없도록 정리해줘

AGENTS.md, .agents/, docs/ 폴더 및 사전 탑재된 유틸리티 파일은 이미 완성되어 있으니 절대 임의로 삭제하거나 덮어쓰지 마 (karpathy-principles.md의 "외과적 변경" 원칙).
```

**확인**: `frontend/`, `backend/`(안에 `venv/`, `requirements.txt`), `vision/`,
`pi/`, `.gitignore`, 그리고 4개의 `.env.example`이 생겼는지 확인합니다.

### Antigravity 인식 확인
Antigravity IDE에서 이 폴더를 워크스페이스로 엽니다. 상단 "…" 메뉴 → **Customizations** 패널에서
Rules/Skills/Workflows 목록에 방금 설치된 항목들이 보이는지 확인합니다. 안 보이면 워크스페이스를
닫았다가 다시 엽니다.

**⚠️ Rules는 3개만 "Always On"으로 설정하세요.** Customizations → Rules에서 아래
3개만 **Always On**으로 켭니다.
- `karpathy-principles` (모든 작업의 기본 전제)
- `security-rules`
- `coding-standards`

나머지 규칙(`api-rules`, `db-rules`, `hardware-rules`, `vision-rules`, `git-rules`,
`deploy-rules`, `ui-ux-rules`)은 Always On으로 켜지 않아도 됩니다 — 각 `agent.md`의
"항상 참고" 항목에 이미 연결돼 있어서, 해당 역할(예: db-agent)을 부를 때 AI가
자동으로 읽습니다. 10개를 전부 Always On으로 켜면 채팅마다 안 쓰는 규칙까지
매번 8,000~12,000 토큰을 소모하므로, 딱 이 3개만 켜는 것이 무료 티어 유지의 핵심입니다.

## 2단계 (1주차). Mock 백엔드 + DB + 대시보드 베이스라인

> 🖥️ **동시 실행 멀티 터미널 안내**:
> IoT 시스템은 여러 프로세스가 실시간으로 통신합니다. **터미널을 3개 열어 각각 실행 상태를 유지**해야 합니다:
> - **터미널 1**: 백엔드 API & WebSocket (`uvicorn main:app --reload --port 8000`)
> - **터미널 2**: Next.js 대시보드 (`npm run dev`)
> - **터미널 3**: 비전 인식 클라이언트 (`python vision/main.py` — 3단계에서 실행)

```
┌─────────────────────────┐   WebSocket / REST    ┌─────────────────────────┐
│  터미널 1: 백엔드 (8000)  │ ◄──────────────────► │ 터미널 2: 프론트엔드(3000) │
└─────────────────────────┘                       └─────────────────────────┘
             ▲
             │ POST /api/v1/vision/events
┌─────────────────────────┐
│  터미널 3: 비전 클라이언트 │
└─────────────────────────┘
```

### 3-1. 웹캠 감지 클라이언트 준비
> ⚠️ **웹캠 충돌 방지 사전 체크 (필수)**:
> Windows는 하나의 웹캠을 한 번에 한 프로그램만 점유할 수 있습니다.

> 실습실 30~40명이 동시에 모델을 다운로드하여 학내망이 차단되는 문제를 막기 위해, `vision/yolov8n.pt`(6.2MB) 가중치 파일이 이미 저장소에 포함되어 있습니다. 별도 다운로드 없이 즉시 실행할 수 있습니다.

```powershell

.\venv\Scripts\Activate.ps1
```

> requirements.txt에 버전별 분기가 들어 있으니 그대로 `pip install -r requirements.txt`를 쓰는 것이 가장 안전합니다.

(만약 `requirements.txt` 대신 직접 설치하려면 아래 명령어 사용):
```powershell

pip install "numpy<2" opencv-python==4.9.0.80 ultralytics requests python-dotenv

# Python 3.13 이상
pip install torch==2.9.1+cpu torchvision==0.24.1+cpu --extra-index-url https://download.pytorch.org/whl/cpu
pip install "opencv-python>=4.10" ultralytics requests python-dotenv
```


### 라즈베리파이 쪽 준비 (직접 실행)
라즈베리파이 5는 `gpiozero` 외에 RP1 칩 제어를 위한 `lgpio`가 필수입니다. 파이 터미널에서:
```bash
cd pi
python3 -m venv venv
source venv/bin/activate
pip install gpiozero lgpio requests python-dotenv
```

Windows PC의 IP를 확인하여 파이에 알려줍니다:
```powershell
ipconfig
# IPv4 주소 확인 (예: 192.168.0.25)
```
그 값을 `pi/.env`의 `BACKEND_URL`에 적습니다:
```
BACKEND_URL=http://192.168.0.25:8000
```

배선은 **전원을 끈 상태**에서, **교사 입회 하**에 연결합니다. 연결 후:
```powershell
# backend/.env
DEVICE_MODE=hardware
```
**확인**: 대시보드 버튼으로 실제 라즈베리파이가 반응하는지 확인합니다.

## 막혔을 때 (FAQ & 트러블슈팅)

| 상황 / 에러 메시지 | 해결 방법 |
|---|---|
| `ModuleNotFoundError: No module named 'backend'` | `backend/main.py` 최상단에 `sys.path` 주입 코드가 포함되어 있는지 확인하거나, `cd backend` 경로에서 `uvicorn main:app`을 실행합니다. |
| `pip freeze` 후 `unsupported mime type charset=utf-16le` 에러 | PowerShell의 기본 리다이렉션 대신 `pip freeze \| Out-File -Encoding utf8 requirements.txt` 명령을 사용합니다. |
| `RuntimeError: The starlette.testclient module requires the httpx package` | 백엔드 가상환경에서 `pip install httpx`를 실행합니다 (`backend/requirements.txt`에 포함됨). |
| Next.js 대시보드 `Hydration failed` 경고 | 시간 렌더링 태그에 `suppressHydrationWarning` 속성을 추가하거나 `components/dashboard/ConnectionBadge.tsx`를 사용합니다. |
| `Control request failed: Failed to fetch` | 백엔드 서버(터미널 1: `http://localhost:8000`)가 켜져 있는지 확인합니다. |
| 웹캠 화면이 검은색으로 나오거나 멈춤 | Zoom, Teams, 브라우저 등 웹캠을 점유 중인 다른 프로그램을 모두 작업 관리자에서 종료합니다. |
| `pip install ultralytics` 경로 길이 오류 (`[WinError 206]`) | 관리자 권한 PowerShell에서 `New-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\FileSystem" -Name "LongPathsEnabled" -Value 1 -PropertyType DWORD -Force` 실행 후 재부팅합니다. |
| `Activate.ps1` 실행 불가 (`PSSecurityException`) | PowerShell에서 `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser` 실행 후 다시 활성화합니다. |
| `mysql: command not found` | `C:\xampp\mysql\bin\mysql.exe -u root`로 직접 지정하거나 phpMyAdmin 웹 UI SQL 탭에 붙여넣어 실행합니다. |
