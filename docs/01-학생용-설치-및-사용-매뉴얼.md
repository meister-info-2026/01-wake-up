## 0단계. GitHub에서 받기 + 하네스 구축 (팀당 딱 한 번만)

### 0-1. 저장소 받기
팀장 또는 백엔드 담당 1명만 하면 됩니다. PowerShell에서:
```powershell
git clone [교사가 안내한 GitHub 저장소 주소] iot-vision-control-system
cd iot-vision-control-system
```
Git이 익숙하지 않다면, GitHub 저장소 페이지에서 **Code → Download ZIP**으로 받아
압축을 풀고 그 폴더로 이동해도 됩니다.

**확인**: `AGENTS.md`, `.agents/`, `docs/`, `backend/`, `frontend/`, `vision/`, `pi/`가 들어있으면 성공입니다 — 공통 인터페이스(`backend/iot/base.py`, `backend/websocket_manager.py`, `frontend/components/dashboard/ConnectionBadge.tsx`)와 모델 가중치(`vision/yolov8n.pt`)는
교사가 미리 완성해서 저장소에 올려둔 것이라 별도 설치 과정이 필요 없습니다.

### 0-2. Antigravity로 열기
Antigravity IDE에서 방금 받은 폴더를 워크스페이스로 엽니다.

### 0-3. 프로젝트 뼈대 완성 (직접 실행 — AI 프롬프트 아님)
`.gitignore`와 4개의 `.env.example`, `backend/requirements.txt`는 **이미 킷에 들어있습니다.**
AI에게 다시 만들어달라고 하지 않습니다(덮어쓰면 `!vision/yolov8n.pt` 예외 규칙 같은 설정이
사라집니다). 여기서 학생이 직접 할 일은 **① Next.js 스캐폴드 생성**과 **② 백엔드 venv 생성**
두 가지뿐입니다.

#### ① frontend/ — Next.js 스캐폴드
> ⚠️ **`frontend/` 안에서 바로 `create-next-app`을 실행하면 실패합니다.**
> `frontend/`에는 이미 `.env.example`과 `components/`가 들어있어서
> `The directory frontend contains files that could conflict:` 메시지와 함께 중단됩니다.
> 아래처럼 **임시 폴더에 만든 뒤 옮기는** 순서로 진행하세요.

```powershell
# 프로젝트 루트에서 실행
npx create-next-app@latest frontend-temp --ts --tailwind --eslint --app --use-npm --disable-git --no-agents-md --yes

# 생성된 파일을 frontend/로 옮긴다 (-Force로 숨김파일 .gitignore까지 포함)
Get-ChildItem -Path frontend-temp -Force | Move-Item -Destination frontend
Remove-Item frontend-temp
```
`--no-agents-md`를 빼먹으면 `frontend/AGENTS.md`가 같이 생겨서 루트 `AGENTS.md`와 헷갈리게
됩니다. 기존 `frontend/.env.example`과 `frontend/components/`는 그대로 남습니다.

#### ② backend/ — 가상환경 생성 및 패키지 설치
```powershell
cd backend
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
cd ..
```
> 💡 **참고**: PowerShell에서 `pip freeze`로 requirements를 저장할 일이 생기면 인코딩 충돌을
> 방지하기 위해 항상 UTF-8로 저장합니다: `pip freeze | Out-File -Encoding utf8 requirements.txt`

**확인**: `frontend/package.json`과 `frontend/app/`, `backend/venv/`가 생겼는지, 그리고
기존 `frontend/components/dashboard/`와 4개의 `.env.example`이 그대로 있는지 확인합니다.

### Antigravity 인식 확인
Antigravity IDE에서 이 폴더를 워크스페이스로 엽니다. 상단 "…" 메뉴 → **Customizations** 패널에서
Rules/Skills/Workflows 목록에 방금 설치된 항목들이 보이는지 확인합니다. 안 보이면 워크스페이스를
닫았다가 다시 엽니다.

**⚠️ Rules는 3개만 "Always On"으로 설정하세요.** Customizations → Rules에서 아래
3개만 **Always On**으로 켭니다.
- `karpathy-principles` (모든 작업의 기본 전제)
- `security-rules`
- `coding-standards`

나머지 규칙(`api-rules`, `db-rules`, `hardware-rules`, `vision-rules`, `git-rules`,
`deploy-rules`, `ui-ux-rules`)은 Always On으로 켜지 않아도 됩니다 — 각 `agent.md`의
"항상 참고" 항목에 이미 연결돼 있어서, 해당 역할(예: db-agent)을 부를 때 AI가
자동으로 읽습니다. 10개를 전부 Always On으로 켜면 채팅마다 안 쓰는 규칙까지
매번 8,000~12,000 토큰을 소모하므로, 딱 이 3개만 켜는 것이 무료 티어 유지의 핵심입니다.

## 1단계. 팀 기획 & AGENTS.md 완성 (PRD 기반 — 토큰 100% 절감)

팀 미팅을 통해 시스템 구성을 합의하고, **무료 웹 ChatGPT/Claude**를 활용해 PRD 작성 후 `AGENTS.md`를 완성합니다 (Gemini API 토큰 소모 0).
상세한 프롬프트와 방법은 **`docs/부록B-ChatGPT-Claude로-AGENTS-작성하기.md`**를 그대로 따릅니다.

1. **팀 미팅**: `docs/부록A-팀-주제-브레인스토밍-워크시트.md`를 참고하여 팀 주제, 센서, 액추에이터, 영상인식 대상, 트리거 규칙, 4인 역할을 정합니다.
2. **PRD 작성**: 브라우저에서 ChatGPT/Claude에 팀 미팅 결과를 전달해 [PRD(제품 요구사항 정의서)]를 작성합니다.
3. **AGENTS.md 완성**: 생성된 `PRD.md` 파일과 스타터 킷의 `AGENTS.md`를 ChatGPT/Claude에 함께 업로드하여 완성된 `AGENTS.md`를 출력받아 워크스페이스에 붙여넣습니다.

### .env 파일 만들기

(`.env`는 `.gitignore`에 있어 커밋되지 않습니다).

## 2단계 (1주차). Mock 백엔드 + DB + 대시보드 베이스라인

> 🖥️ **동시 실행 멀티 터미널 안내**:
> IoT 시스템은 여러 프로세스가 실시간으로 통신합니다. **터미널을 3개 열어 각각 실행 상태를 유지**해야 합니다:
> - **터미널 1**: 백엔드 API & WebSocket (`uvicorn main:app --reload --port 8000`)
> - **터미널 2**: Next.js 대시보드 (`npm run dev`)
> - **터미널 3**: 비전 인식 클라이언트 (`vision/`에서 `python main.py` — 3단계에서 실행)

```
┌─────────────────────────┐   WebSocket / REST    ┌─────────────────────────┐
│  터미널 1: 백엔드 (8000)  │ ◄──────────────────► │ 터미널 2: 프론트엔드(3000) │
└─────────────────────────┘                       └─────────────────────────┘
             ▲
             │ POST /api/v1/vision/events
┌─────────────────────────┐
│  터미널 3: 비전 클라이언트 │
└─────────────────────────┘
```

### 2-2-1. DB 초기화 스크립트 실행 (직접 실행)
AI가 만든 `init.sql`은 파일로만 존재할 뿐, 아직 MySQL에 반영되지 않았습니다.
XAMPP MySQL이 켜진 상태에서 PowerShell로 직접 실행합니다.
(터미널 1은 이미 `backend`에 있으므로 `cd`를 다시 하지 않습니다.)
```powershell
# [터미널 1] — 현재 위치가 backend/ 인 상태
Get-Content db\init.sql | mysql -u root
```
> ⚠️ `init.sql` 맨 위에 `CREATE DATABASE IF NOT EXISTS ...;` 와 `USE ...;` 두 줄이 있어야
> 합니다. 없으면 `ERROR 1046 (3D000): No database selected`가 납니다. 두 줄이 없다면
> `mysql -u root smart_control` 처럼 DB 이름을 직접 붙여서 실행하세요.

(mysql 명령이 PATH에 없다면, phpMyAdmin 웹 화면의 **SQL 탭**에 `init.sql` 내용을 그대로 붙여넣어 실행해도 됩니다.)

**확인**: phpMyAdmin에서 `devices` 테이블에 우리 팀 디바이스 행이 들어있는지 확인합니다.

```
너는 이 프로젝트의 hardware-agent다. .agents/skills/hardware-integration/SKILL.md를 따른다.

backend/iot/base.py의 DeviceProvider를 상속받아 우리 팀 액추에이터([예: 도어락, LED])와 
센서([예: 온습도])에 대한 MockDeviceProvider를 만들어줘. devices 테이블의 id 값과 일치시켜줘.
```

```
너는 이 프로젝트의 backend-agent다. .agents/skills/iot-endpoint-generator/SKILL.md를 따른다.

우리 팀 디바이스 전체에 대한 조회/제어 엔드포인트와 backend/main.py 라우팅을 완성해줘.
```

## 3단계 (2주차). 영상인식 → IoT 제어 트리거

### 3-1. 웹캠 감지 클라이언트 준비
> ⚠️ **웹캠 충돌 방지 사전 체크 (필수)**:
> Windows는 하나의 웹캠을 한 번에 한 프로그램만 점유할 수 있습니다.
> 시작 전에 **Zoom, Teams, Discord, 브라우저 화상채팅, Windows 카메라 앱 등을 모두 종료**하세요.

> 🚀 **YOLOv8 모델 사전 탑재 안내**:
> 실습실 30~40명이 동시에 모델을 다운로드하여 학내망이 차단되는 문제를 막기 위해, `vision/yolov8n.pt`(6.2MB) 가중치 파일이 이미 저장소에 포함되어 있습니다. 별도 다운로드 없이 즉시 실행할 수 있습니다.

새 터미널(터미널 3)에서 의존성을 설치합니다:
```powershell
# [터미널 3]
cd vision
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```
> ⚠️ **파이썬 버전 주의**: `python --version`이 **3.13 이상**이면 torch 2.2.2 휠이 없어
> 그냥 설치하면 실패합니다. `vision/requirements.txt`에 파이썬 버전별 분기(환경 마커)가
>들어 있으므로, **그대로 `pip install -r requirements.txt`를 쓰는 것이 가장 안전합니다.**

(만약 `requirements.txt` 대신 직접 설치하려면 아래 명령어 사용):
```powershell
# Python 3.10 ~ 3.14 공통 — 설치된 파이썬 버전에 맞는 최신 CPU 휠을 받습니다
python -m pip install --upgrade pip
python -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
python -m pip install --upgrade opencv-python ultralytics requests python-dotenv
```

```
너는 이 프로젝트의 vision-agent다. .agents/skills/vision-recognition-integration/SKILL.md를
따른다.

사전 포함된 vision/yolov8n.pt 모델을 로드하여, AGENTS.md 팀 정보의 "영상인식 감지 대상"을 
실시간 감지하고 이벤트를 백엔드로 전송하는 vision/main.py를 작성해줘.
```

완성되면 직접 실행해서 확인합니다:
```powershell
# [터미널 3] — 현재 위치가 vision/ 인 상태
python main.py
```
**확인**: 웹캠 창이 뜨고, 사람이 감지되면 콘솔에 백엔드로 이벤트 전송 로그가 찍히는지 확인합니다.

### 3-2. 백엔드 트리거 로직 연결
```
너는 이 프로젝트의 backend-agent다.

vision_events를 받아서 AGENTS.md 팀 정보의 "트리거 규칙"대로 액추에이터
```

**확인**: 웹캠 앞에서 감지 대상을 노출/제거할 때 대시보드의 액추에이터 상태가 자동으로 바뀌는지 눈으로 확인합니다.

## 4단계 (3주차). 하드웨어 마이그레이션 (Mock → 라즈베리파이 5)

`.agents/workflows/hardware-swap.md`를 그대로 따릅니다.

> 💡 이 단계를 완료한 뒤부터 라즈베리파이 5 관련 개발(새 액추에이터 추가, 배선 변경 등)을
> 별도 담당자가 이어받는 팀이라면, 백엔드·DB 담당자와 라즈베리파이 담당자가 서로의 코드를
> 매번 확인하지 않고도 협업할 수 있도록 **`docs/부록C-백엔드-라즈베리파이5-연동-인터페이스-가이드.md`**
> 를 함께 참고합니다.

> ⚠️ **라즈베리파이 담당자가 임시 테스트 시스템(`iot-test-system` + `antigravity-plugin`)으로
> 먼저 연습한 팀이라면 이 단계 전에 반드시 읽으세요:
> [`docs/부록D-iot-test-system-연동-가이드.md`](부록D-iot-test-system-연동-가이드.md)**
> 두 시스템은 인증 헤더(`X-Device-Key` ↔ `X-Device-Api-Key`), 경로(`/api/` ↔ `/api/v1/`),
> 디바이스 식별 단위가 전부 달라서 파이 담당자의 연습 코드가 그대로 붙지 않습니다.
> 백엔드 담당자가 먼저 넘겨줘야 할 값들이 그 문서 4장에 체크리스트로 정리돼 있습니다.

이 단계에서 만드는 파일은 **두 개**입니다. 역할이 다르므로 프롬프트도 나눠서 넣습니다.

| 파일 | 실행 위치 | 하는 일 |
|---|---|---|
| `backend/iot/hardware_provider.py` + `provider_factory.py` | Windows PC(백엔드) | desired-state를 DB에 저장/제공하는 **중계** 역할. GPIO를 직접 만지지 않는다 |
| `pi/main.py` | 라즈베리파이 | 백엔드를 폴링해서 **실제 GPIO를 제어**하고 결과를 보고 |

**① 백엔드 쪽 (백엔드·DB 담당자)**
```
너는 이 프로젝트의 hardware-agent다. .agents/rules/hardware-rules.md와
.agents/skills/hardware-integration/SKILL.md를 따른다.

backend/iot/base.py의 DeviceProvider(async 4개 메서드)를 상속받는
hardware_provider.py와, .env의 DEVICE_MODE로 mock/hardware Provider를 골라 반환하는
provider_factory.py를 backend/iot/에 만들어줘. hardware_provider는 GPIO를 직접
제어하지 않고 desired_state/current_state를 DB에 저장·조회하는 중계 역할만 한다
(실제 GPIO 제어는 라즈베리파이의 pi/main.py 담당).
```

**② 라즈베리파이 쪽 (라즈베리파이 담당자)**
```
너는 이 프로젝트의 hardware-agent다. .agents/rules/hardware-rules.md와
.agents/skills/hardware-integration/SKILL.md를 따른다.

docs/부록C-백엔드-라즈베리파이5-연동-인터페이스-가이드.md의 3장 REST 계약대로 pi/main.py의
폴링 루프(desired-state 조회 → gpiozero/lgpio로 반영 → state 보고)를 만들어줘.
pi/main.py는 backend/iot/base.py를 import하지 않는다 (다른 기기에서 도는 별도 프로세스라
import 자체가 불가능하다) — 같은 4개 메서드 이름만 맞춘 독립 클래스로 만들어줘.
```

### 라즈베리파이 쪽 준비 (직접 실행)
라즈베리파이 5는 `gpiozero` 외에 RP1 칩 제어를 위한 `lgpio`가 필수입니다. 파이 터미널에서:
```bash
cd pi
python3 -m venv venv
source venv/bin/activate
pip install gpiozero lgpio requests python-dotenv
```

Windows PC의 IP를 확인하여 파이에 알려줍니다:
```powershell
ipconfig
# IPv4 주소 확인 (예: 192.168.0.25)
```
그 값을 `pi/.env`의 `BACKEND_URL`에 적습니다:
```
BACKEND_URL=http://192.168.0.25:8000
```

배선은 **전원을 끈 상태**에서, **교사 입회 하**에 연결합니다. 연결 후 `backend/.env`를
편집해 아래 값으로 바꾸고 백엔드를 재시작합니다(다른 파일은 건드리지 않습니다):
```
DEVICE_MODE=hardware
```
**확인**: 대시보드 버튼으로 실제 라즈베리파이가 반응하는지 확인합니다.

## 막혔을 때 (FAQ & 트러블슈팅)

| 상황 / 에러 메시지 | 해결 방법 |
|---|---|
| `ModuleNotFoundError: No module named 'backend'` | `backend/main.py` 최상단에 `sys.path` 주입 코드가 포함되어 있는지 확인하거나, `cd backend` 경로에서 `uvicorn main:app`을 실행합니다. |
| `pip freeze` 후 `unsupported mime type charset=utf-16le` 에러 | PowerShell의 기본 리다이렉션 대신 `pip freeze \| Out-File -Encoding utf8 requirements.txt` 명령을 사용합니다. |
| `RuntimeError: The starlette.testclient module requires the httpx package` | 백엔드 가상환경에서 `pip install httpx`를 실행합니다 (`backend/requirements.txt`에 포함됨). |
| Next.js 대시보드 `Hydration failed` 경고 | 시간 렌더링 태그에 `suppressHydrationWarning` 속성을 추가하거나 `components/dashboard/ConnectionBadge.tsx`를 사용합니다. |
| `Control request failed: Failed to fetch` | 백엔드 서버(터미널 1: `http://localhost:8000`)가 켜져 있는지 확인합니다. |
| 웹캠 화면이 검은색으로 나오거나 멈춤 | Zoom, Teams, 브라우저 등 웹캠을 점유 중인 다른 프로그램을 모두 작업 관리자에서 종료합니다. |
| `pip install ultralytics` 경로 길이 오류 (`[WinError 206]`) | 관리자 권한 PowerShell에서 `New-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\FileSystem" -Name "LongPathsEnabled" -Value 1 -PropertyType DWORD -Force` 실행 후 재부팅합니다. |
| `Activate.ps1` 실행 불가 (`PSSecurityException`) | PowerShell에서 `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser` 실행 후 다시 활성화합니다. |
| `mysql: command not found` | `C:\xampp\mysql\bin\mysql.exe -u root`로 직접 지정하거나 phpMyAdmin 웹 UI SQL 탭에 붙여넣어 실행합니다. |
